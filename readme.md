# Strawberry Growth Cycle Detection Dataset VOC+YOLO format with 2949 images in 4 categories

Dataset format: Pascal VOC format + YOLO format (txt file without split path, only containing jpg images and corresponding VOC format xml files and yolo format txt files)

Number of images (number of jpg files): 2949

Number of annotations (number of xml files): 2949

Number of annotations (number of txt files): 2949

Labeling category count: 4

Label category names (Note that the order of categories in the YOLO format does not correspond to this, but is based on the labels folder's classes.txt): ["Turning", "flower", "ripe", "unripe"]

Number of boxes labeled in each category:

Turning Frames = 1637

Flower frame count = 1283

Ripe frame count = 4118

Unripe frame count = 8055

Total frame count: 15093

Using labelImg:

Annotation rules: Draw a rectangle around the category.

Important Notice: No

Special : This dataset does not guarantee the accuracy or precision of the trained models or weight files. The dataset is provided with accurate and reasonable annotations only.
